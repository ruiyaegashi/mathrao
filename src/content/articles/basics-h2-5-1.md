## 指数の定義と指数法則




【定義】




$a \neq 0$ で，$n$ が正の整数のとき


<ul>
	<li>$a^0=1$</li>
	<li>$a^{-n}= \frac{1}{a^n}$ 特に $a^{-1}= \frac{1}{a}$</li>
</ul>


【法則】




<strong>指数法則</strong>




$a \neq 0$，$b \neq 0$ で，$m$，$n$ が整数のとき


<ul>
	<li>$a^ma^n=a^{m+n}$</li>
	<li>$\displaystyle \frac{a^m}{a^n} =a^{m-n}$</li>
	<li>$(a^m)^n=a^{mn}$</li>
	<li>$(ab)^n=a^nb^n$</li>
	<li>$\left( \displaystyle \frac{a}{b} \right)^n= \displaystyle \frac{a^n}{b^n}$</li>
</ul>







## 累乗根




【定義】




$\boldsymbol{a}$ の $\boldsymbol{n}$ <strong>乗根</strong>：$n$ を正の整数とするとき，$n$ 乗すると $a$ になる数




<strong>累乗根</strong>：2乗根，3乗根，……をまとめたもの


<ul>
	<li>$n$ が奇数のとき：$a$ の正負に関係なくただ1つあり，$\sqrt[n]{a}$ で表す。</li>
	<li>$n$ が偶数のとき：$a&gt;0$ なら正負2つあり，$\pm \sqrt[n]{a}$ で表す。$a&lt;0$ なら実数の範囲には存在しない。</li>
	<li>$\sqrt[n]{0} =0$</li>
</ul>


【定理】




<strong>累乗根の性質</strong>




$a>0$，$b>0$ で，$m$，$n$，$p$ が正の整数のとき


<ul>
	<li>$( \sqrt[n]{a} )^n =a$</li>
	<li>$\sqrt[n]{a} \sqrt[n]{b} = \sqrt[n]{ab}$</li>
	<li>$\displaystyle \frac{\sqrt[n]{a}}{\sqrt[n]{b}} = \sqrt[n]{\frac{a}{b}}$</li>
	<li>$( \sqrt[n]{a} )^m = \sqrt[n]{a^m}$</li>
	<li>$\sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{a}$</li>
	<li>$\sqrt[n]{a^m} = \sqrt[np]{a^{mp}}$</li>
</ul>







## 有理数の指数




【定義】




$a>0$ で，$m$，$n$ が正の整数，$r$ が正の有理数のとき


<ul>
	<li>$a^{\frac{m}{n}}= \sqrt[n]{a^m} =( \sqrt[n]{a} )^m$ 特に $a^{\frac{1}{n}} = \sqrt[n]{a}$</li>
	<li>$a^{-r} = \displaystyle \frac{1}{a^r}$</li>
</ul>


【法則】




<strong>指数法則</strong>




$a>0$，$b>0$ で，$r$，$s$ が有理数のとき


<ul>
	<li>$a^ra^s=a^{r+s}$</li>
	<li>$\displaystyle \frac{a^r}{a^s} = a^{r-s}$</li>
	<li>$(a^r)^s=a^{rs}$</li>
	<li>$(ab)^r=a^rb^r$</li>
	<li>$\left( \displaystyle \frac{a}{b} \right)^r = \displaystyle \frac{a^r}{b^r}$</li>
</ul>







## 指数関数




【定義】




$a$ を<strong>底</strong>とする $x$ の<strong>指数関数</strong>：$y=a^x$ ( $a>0$，$a \neq 1$ )




<strong>増加関数</strong>：$x$ の値が増加すると $y$ の値が増加する関数




<strong>減少関数</strong>：$x$ の値が増加すると $y$ の値が減少する関数









## 指数関数のグラフ




指数関数のグラフの特徴・性質


<ul>
	<li>曲線</li>
	<li>点 $(0,1)$，$(1,a)$ を通る</li>
	<li>$x$ 軸が漸近線</li>
	<li>$0&lt;a&lt;1$ のとき減少関数：$p&lt;q \Leftrightarrow a^p&lt;a^q$</li>
	<li>$1&lt;a$ のとき増加関数：$p&lt;q \Leftrightarrow a^p&gt;a^q$</li>
	<li>定義域は実数全体，値域は正の数全体</li>
</ul>







## 指数方程式・指数不等式




【定義】




<strong>指数方程式</strong>：指数関数を含む方程式




<strong>指数不等式</strong>：指数関数を含む不等式




底を $a$ ( $a>0$，$a \neq 1$ )，$b$ を定数とすると


<ul>
	<li>方程式 $a^x=a^b$ の解は $x=b$</li>
	<li>不等式 $a^x&gt;a^b$ の解は $0&lt;a&lt;1$ のとき $x&lt;b$，$1&lt;a$ のとき $x&gt;b$</li>
	<li>不等式 $a^x&lt;a^b$ の解は $0&lt;a&lt;1$ のとき $x&gt;b$，$1&lt;a$ のとき $x&lt;b$</li>
</ul>
