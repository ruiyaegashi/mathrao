## 加法定理と2倍角，半角，3倍角，積和，和積の公式




【定理】




<strong>加法定理</strong>


<ul>
	<li>$\sin ( \alpha \pm \beta )= \sin \alpha \cos \beta \pm \cos \alpha \sin \beta$</li>
	<li>$\cos ( \alpha \pm \beta )= \cos \alpha \cos \beta \mp \sin \alpha \sin \beta$</li>
	<li>$\tan ( \alpha \pm \beta )= \displaystyle \frac{\tan \alpha \pm \beta}{1 \mp \tan \alpha \tan \beta}$</li>
</ul>


<strong>2倍角の公式</strong>


<ul>
	<li>$\sin 2 \alpha =2 \sin \alpha \cos \alpha$</li>
	<li>$\cos 2 \alpha = \cos^2 \alpha - \sin^2 \alpha =1-2 \sin^2 \alpha =2 \cos^2 \alpha -1$</li>
	<li>$\tan 2 \alpha = \displaystyle \frac{2 \tan \alpha}{1- \tan^2 \alpha}$</li>
</ul>


<strong>半角の公式</strong>


<ul>
	<li>$\sin^2 \displaystyle \frac{\alpha}{2} = \frac{1- \cos \alpha}{2}$</li>
	<li>$\cos^2 \displaystyle \frac{\alpha}{2} = \frac{1+ \cos \alpha}{2}$</li>
	<li>$\tan^2 \displaystyle \frac{\alpha}{2} = \frac{1- \cos \alpha}{1+ \cos \alpha}$</li>
</ul>


<strong>3倍角の公式</strong>


<ul>
	<li>$\sin 3 \alpha = -4 \sin^3 \alpha +3 \sin \alpha$</li>
	<li>$\cos 3 \alpha = 4 \cos^3 \alpha -3 \cos \alpha$</li>
	<li>$\tan 3 \alpha = \displaystyle \frac{\tan^3 -3 \tan \alpha}{3 \tan^2 \alpha -1}$</li>
</ul>


<strong>積和の公式</strong>


<ul>
	<li>$\sin \alpha \cos \beta = \frac{1}{2} \{ \sin ( \alpha + \beta )+ \sin (\alpha - \beta ) \}$</li>
	<li>$\cos \alpha \sin \beta = \frac{1}{2} \{ \sin ( \alpha + \beta )- \sin (\alpha - \beta ) \}$</li>
	<li>$\cos \alpha \cos \beta = \frac{1}{2} \{ \cos ( \alpha + \beta )+ \cos (\alpha - \beta ) \}$</li>
	<li>$\sin \alpha \sin \beta =-\frac{1}{2} \{ \cos ( \alpha + \beta )- \cos (\alpha - \beta ) \}$</li>
</ul>


<strong>和積の公式</strong>


<ul>
	<li>$\sin A+ \sin B=2 \sin \displaystyle \frac{A+B}{2} \cos \frac{A-B}{2}$</li>
	<li>$\sin A- \sin B=2 \cos \displaystyle \frac{A+B}{2} \sin \frac{A-B}{2}$</li>
	<li>$\cos A+ \cos B=2 \cos \displaystyle \frac{A+B}{2} \cos \frac{A-B}{2}$</li>
	<li>$\cos A+ \cos B=-2 \sin \displaystyle \frac{A+B}{2} \sin \frac{A-B}{2}$</li>
</ul>

## 2直線のなす角




交わる2直線 $y=m_1x+n_1$，$y=m_2x+n_2$ が垂直でないとき，この2直線のなす鋭角を $\theta$ とすると


<p style="padding-left: 30px;">$\tan \theta = \displaystyle \left| \frac{m_1-m_2}{1+m_1m_2} \right|$</p>

## 三角関数の合成




【定理】




<strong>三角関数の合成</strong>




$a \sin \theta +b \cos \theta = \sqrt{a^2+b^2} \sin ( \theta + \alpha )$




ただし $\sin \alpha = \displaystyle \frac{b}{\sqrt{a^2+b^2}}$，$\cos \alpha = \displaystyle \frac{a}{\sqrt{a^2+b^2}}$
