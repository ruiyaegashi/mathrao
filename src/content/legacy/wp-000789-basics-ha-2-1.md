## 線分の内分点・外分点




【定義】




点 $\mathrm{P}$ が線分 $\mathrm{AB}$ を $m:n$ に<strong>内分</strong>する：$m$，$n$ を正の数としたとき，線分 $\mathrm{AB}$ 上の点 $\mathrm{P}$ が $\mathrm{AP} : \mathrm{PB} =m:n$ を満たすこと




<strong>内分点</strong>：内分する点




点 $\mathrm{Q}$ が線分 $\mathrm{AB}$ を $m:n$ に<strong>外分</strong>する：$m$，$n$ を正の数としたとき，線分 $\mathrm{AB}$ の延長上の点 $\mathrm{Q}$ が $\mathrm{AQ} : \mathrm{QB} =m:n$ を満たすこと




<strong>内分点</strong>：外分する点

## 三角形の角の二等分線と比




【定理】




<strong>平行線と同位角・錯角，辺の比</strong>


<ul>
	<li>平行な2直線に1直線が交わるとき，同位角，錯角はそれぞれ等しい</li>
	<li>$\triangle \mathrm{ABC}$ の辺 $\mathrm{AB}$ 上に点 $\mathrm{P}$ があり，辺 $\mathrm{AC}$ 上に点 $\mathrm{Q}$ があるとき<br />
$\mathrm{PQ} /\!/ \mathrm{BC} \Leftrightarrow \mathrm{AP} : \mathrm{AB} = \mathrm{AQ} : \mathrm{AC}$<br />
$\mathrm{PQ} /\!/ \mathrm{BC} \Leftrightarrow \mathrm{AP} : \mathrm{PB} = \mathrm{AQ} : \mathrm{QC}$<br />
$\mathrm{PQ} /\!/ \mathrm{BC} \Leftrightarrow \mathrm{AP} : \mathrm{AB} = \mathrm{PQ} : \mathrm{BC}$</li>
</ul>


<strong>三角形の内角の二等分線と辺の比</strong>




$\triangle \mathrm{ABC}$ の $\angle \mathrm{A}$ の二等分線と辺 $\mathrm{BC}$ との交点 $\mathrm{P}$ は，辺 $\mathrm{BC}$ を $\mathrm{AB} : \mathrm{AC}$ に内分する。




<strong>三角形の外角の二等分線と辺の比</strong>




$\mathrm{AB} \neq \mathrm{AC}$ である $\triangle \mathrm{ABC}$ の頂点 $\mathrm{A}$ における外角の二等分線と辺 $\mathrm{BC}$ の延長との交点 $\mathrm{Q}$ は，辺 $\mathrm{BC}$ を $\mathrm{AB} : \mathrm{AC}$ に外分する。

## 三角形の五心




【定義】




<strong>外接円</strong>：三角形の3つの頂点を通る円




<strong>外心</strong>：外接円の中心




<strong>内接円</strong>：三角形の3辺に接する円




<strong>内心</strong>：内接円の中心




<strong>中線</strong>：三角形の頂点と向かい合う辺の中点を結ぶ線分




<strong>重心</strong>：三角形の3本の中線の交点




<strong>垂心</strong>：三角形の3つの頂点から向かい合う辺に下ろした垂線の交点




<strong>傍接円</strong>：三角形の1辺と他の2辺の延長に接する円




<strong>傍心</strong>：傍接円の中心


<p style="padding-left: 30px;">※傍心・傍接円は3つある。</p>


【定理】




<strong>外心</strong>




三角形の3辺の垂直二等分線は1点で交わる。




<strong>内心</strong>




三角形の3つの内角の二等分線は1点で交わる。




<strong>重心</strong>




三角形の3本の中線は1点で交わり，その点は各中線を $2:1$ に内分する。




<strong>垂心</strong>




三角形の3つの頂点から向かい合う辺に下ろした垂線1点で交わる。




<strong>傍心</strong>




三角形の1つの頂点における内角の二等分線と，他の2つの頂点における外角の二等分線は1点で交わる。

## 中線定理




【定理】




<strong>中線定理</strong>




$\triangle \mathrm{ABC}$ の辺 $\mathrm{BC}$ の中点を $\mathrm{M}$ とすると


<p style="padding-left: 30px;">$\mathrm{AB}^2 + \mathrm{AC}^2 =2( \mathrm{AM}^2 + \mathrm{BM}^2 )$</p>
