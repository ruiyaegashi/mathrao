## 正，負の数の乗法




【定義】




<strong>乗法</strong>：かけ算




<strong>積</strong>：乗法の結果




<strong>除法</strong>：わり算




<strong>商</strong>：除法の結果


<ul>
	<li>同符号の2数の積は，絶対値の積に正の符号をつける。</li>
	<li>異符号の2数の積は，絶対値の積に負の符号をつける。</li>
	<li>同符号の2数の商は，絶対値の商に正の符号をつける。</li>
	<li>異符号の2数の商は，絶対値の商に負の符号をつける。</li>
	<li>正，負の数でわることは，その数の逆数をかけることと同じ。</li>
</ul>


&nbsp;




## 計算法則




【法則】




<strong>乗法の交換法則</strong>


<p style="padding-left: 30px;">$a \times b=b \times a$</p>


<strong>乗法の結合法則</strong>


<p style="padding-left: 30px;">$( a \times b ) \times c = a \times ( b \times c )$</p>


<strong>分配法則</strong>


<p style="padding-left: 30px;">$a \times ( b + c ) = a \times b + a \times c$</p>
<p style="padding-left: 30px;">$( b + c ) \times a = b \times a + c \times a$</p>


&nbsp;




## 積の符号と絶対値




いくつかの数の積について，次のようにまとめることができる。


<p style="padding-left: 30px;">$( 積の符号 ) = \begin{cases} + &amp; ( 負の数が偶数個 ) \\- &amp; ( 負の数が奇数個 ) \end{cases}$</p>
<p style="padding-left: 30px;">$( 積の絶対値 ) = ( かけ合わせる数の絶対値の積 )$</p>

## 累乗




【定義】




<strong>累乗</strong>：同じ数をいくつかかけ合わせたもの




<strong>指数</strong>：いくつかけ合わせたかを示す数




&nbsp;




## 四則の混じった計算




四則やかっこの混じった計算の順序


<ul>
	<li>累乗があるときは，累乗を先に計算する。</li>
	<li>加減と乗除が混じっているときは，乗除を先に計算する。</li>
	<li>かっこがあるときは，かっこの中を先に計算する。</li>
</ul>
