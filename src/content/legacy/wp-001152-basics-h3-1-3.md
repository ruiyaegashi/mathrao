## 線分の内分点，外分点




複素数平面上において，2点 $\mathrm{A}(\alpha)$，$\mathrm{B}(\beta)$ を結ぶ線分 $\mathrm{AB}$ を $m:n$ に内分する点を $\mathrm{C}(\gamma)$，$m:n$ に外分する点を $\mathrm{D}(\delta)$ とすると


<ul>
	<li>内分点：$\gamma=\displaystyle\frac{n\alpha+m\beta}{m+n}$</li>
	<li>外分点：$\delta=\displaystyle\frac{-n\alpha+m\beta}{m-n}$</li>
	<li>線分 $\mathrm{AB}$ の中点：$\displaystyle\frac{\alpha+\beta}{2}$</li>
</ul>


&nbsp;




## 方程式・不等式の表す図形




複素数平面上の異なる2点を $\mathrm{A}(\alpha)$，$\mathrm{B}(\beta)$ とすると


<ul>
	<li>方程式 $|z-\alpha|=|z-\beta|$ を満たす点 $\mathrm{P}(z)$ 全体は線分 $\mathrm{AB}$ の垂直二等分線</li>
	<li>方程式 $|z-\alpha|=r$ ( $r&gt;0$ )を満たす点 $\mathrm{P}(z)$ 全体は点 $\mathrm{A}$ を中心とする半径 $r$ の円</li>
	<li>方程式 $|z-\alpha|&lt;r$ ( $r&gt;0$ )を満たす点 $\mathrm{P}(z)$ 全体は点 $\mathrm{A}$ を中心とする半径 $r$ の円の内部</li>
	<li>方程式 $|z-\alpha|\leqq r$ ( $r&gt;0$ )を満たす点 $\mathrm{P}(z)$ 全体は点 $\mathrm{A}$ を中心とする半径 $r$ の円の周および内部</li>
	<li>方程式 $|z-\alpha|&gt;r$ ( $r&gt;0$ )を満たす点 $\mathrm{P}(z)$ 全体は点 $\mathrm{A}$ を中心とする半径 $r$ の円の外部</li>
	<li>方程式 $|z-\alpha|\geqq r$ ( $r&gt;0$ )を満たす点 $\mathrm{P}(z)$ 全体は点 $\mathrm{A}$ を中心とする半径 $r$ の円の周および外部</li>
	<li>方程式 $n|z-\alpha|=m|z-\beta|$ ( $m&gt;0$，$n&gt;0$，$m\neq n$ )を満たす点 $\mathrm{P}(z)$ 全体は線分 $\mathrm{AB}$ を $m:n$ の比に内分する点と外分する点を直径の両端とする円(アポロニウスの円)</li>
</ul>


&nbsp;




## 線分のなす角，平行・垂直




複素数平面上の異なる4点を $\mathrm{A}(\alpha)$，$\mathrm{B}(\beta)$，$\mathrm{C}(\gamma)$，$\mathrm{D}(\delta)$ とし，偏角 $\theta$ は $-\pi&lt;\theta\leqq\pi$ で考えるものとすると


<ul>
	<li>$\angle \mathrm{BAC}=\left|\mathrm{arg}\displaystyle\frac{\gamma-\alpha}{\beta-\alpha}\right|$</li>
	<li>3点 $\mathrm{A}$，$\mathrm{B}$，$\mathrm{C}$ が同じ直線上にある $\Leftrightarrow$ $\displaystyle\frac{\gamma-\alpha}{\beta-\alpha}$ が実数 (偏角が $0$，$\pi$ )</li>
	<li>$\mathrm{AB}\perp\mathrm{AC}$ $\Leftrightarrow$ $\displaystyle\frac{\gamma-\alpha}{\beta-\alpha}$ が純虚数 (偏角が $\pm\frac{\pi}{2}$ )</li>
	<li>$\mathrm{AB}/\!/\mathrm{CD}$ $\Leftrightarrow$ $\displaystyle\frac{\delta-\gamma}{\beta-\alpha}$ が実数</li>
	<li>$\mathrm{AB}\perp\mathrm{CD}$ $\Leftrightarrow$ $\displaystyle\frac{\delta-\gamma}{\beta-\alpha}$ が純虚数</li>
</ul>
