## 座標を用いた三角比の定義




【定義】




座標平面上の原点を中心とした半径 $r$ の円の円周上に点 $\mathrm{P} (x,y)$ をとり，円と $x$ 軸正の向きの交点を点 $\mathrm{A}$，$\angle \mathrm{AOP} = \theta$ ( $0^{ \circ } \leqq \theta \leqq 180^{ \circ }$ )とすると


<p style="padding-left: 30px;">$\sin \theta = \frac{y}{r}$，$\cos \theta = \frac{x}{r}$，$\tan \theta = \frac{y}{x}$ ( $\theta \neq 90^{ \circ }$ )</p>
<p style="padding-left: 30px;">※特に，半径1の円(<strong>単位円</strong>)の場合</p>
<p style="padding-left: 60px;">$\sin \theta =y$，$\cos \theta =x$，$\tan \theta = \frac{y}{x}$ ( $\theta \neq 90^{ \circ }$ )</p>

## 三角比の範囲




$0^{ \circ } \leqq \theta \leqq 180^{ \circ }$ のとき


<p style="padding-left: 30px;">$0 \leqq \sin \theta \leqq 1$</p>
<p style="padding-left: 30px;">$-1 \leqq \cos \theta \leqq 1$</p>
<p style="padding-left: 30px;">$\tan \theta$ はすべての実数値をとる</p>


&nbsp;




## 三角比の角の変換




【定理】




$180^{ \circ } - \theta$ の三角比( $0^{ \circ } \leqq \theta \leqq 180^{ \circ }$ )


<p style="padding-left: 30px;">$\sin (180^{ \circ } - \theta )= \sin \theta$</p>
<p style="padding-left: 30px;">$\cos (180^{ \circ } - \theta )=- \cos \theta$</p>
<p style="padding-left: 30px;">$\tan (180^{ \circ } - \theta )=- \tan \theta$</p>


$90^{ \circ } + \theta$ の三角比( $0^{ \circ } \leqq \theta \leqq 90^{ \circ }$ )


<p style="padding-left: 30px;">$\sin (90^{ \circ } + \theta )= \cos \theta$</p>
<p style="padding-left: 30px;">$\cos (90^{ \circ } + \theta )=- \sin \theta$</p>
<p style="padding-left: 30px;">$\tan (90^{ \circ } + \theta )=- \displaystyle \frac{1}{ \tan \theta}$ ( $\theta \neq 0^{ \circ },90^{ \circ }$ )</p>


&nbsp;




## 三角方程式




【定義】




<strong>三角方程式</strong>：未知の角の三角比を含む方程式




三角方程式を<strong>解く</strong>：方程式を満たす角を求めること




&nbsp;




## 三角比の相互関係(2)




【定理】




$0^{ \circ } \leqq \theta \leqq 180^{ \circ }$ のとき( $\tan \theta$ では $\theta \neq 90^{ \circ }$ )


<p style="padding-left: 30px;">$\tan \theta = \displaystyle \frac{ \sin \theta}{ \cos \theta}$</p>
<p style="padding-left: 30px;">$\sin^2 \theta + \cos^2 \theta =1$</p>
<p style="padding-left: 30px;">$1+ \tan \theta = \displaystyle \frac{1}{ \cos^2 \theta}$</p>


&nbsp;




## 直線の傾きと正接




傾き $m$ の直線と $x$ 軸の性の向きとのなす角を $\theta$ ( $0^{ \circ } \leqq \theta &lt; 180^{ \circ }$ )とすると $\boldsymbol{m= \tan \theta}$ ( $\theta \neq 90^{ \circ }$ )である。
