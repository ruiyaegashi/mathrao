合同式は，学習指導要領の範囲外の内容であるが，整数の問題を処理するときにはとても有用であるので，ここで扱っておく。




以下，$m$ は正の整数，$a$，$b$ は整数とする。




&nbsp;




## 合同式




【定義】




$a$，$b$ が $m$ を法として<strong>合同</strong>：$a-b$ が $m$ の倍数であること




<strong>合同式</strong>：$a$，$b$ が $m$ を法として合同を $a \equiv b ( \bmod m)$ と表したもの


<p style="padding-left: 30px;">※$a$ と $b$ が $m$ を法として合同であるとき，次の関係が成り立つ。</p>
<p style="padding-left: 60px;">$a \equiv b ( \bmod m)$</p>
<p style="padding-left: 60px;">$\Leftrightarrow$ $a-b$ が $m$ の倍数 [$a-b=mk$ ( $k$ は整数)] ：定義</p>
<p style="padding-left: 60px;">$\Leftrightarrow$ ( $a$ を $m$ で割った余り) $=$ ( $b$ を $m$ で割った余り)</p>


&nbsp;




## 合同式の性質




【定理】




<strong>合同式の性質Ⅰ</strong>


<ul>
	<li>$a \equiv a ( \bmod m)$</li>
	<li>$a \equiv b ( \bmod m)$ のとき $b \equiv a ( \bmod m)$</li>
	<li>$a \equiv b ( \bmod m)$，$b \equiv c ( \bmod m)$ のとき $a \equiv c ( \bmod m)$</li>
</ul>
<p style="padding-left: 30px;">※$a \equiv b ( \bmod m)$，$b \equiv c ( \bmod m)$ を $a \equiv b \equiv c ( \bmod m)$ と書いても良い。</p>


<strong>合同式の性質Ⅱ</strong>




$a \equiv b ( \bmod m)$，$c \equiv d ( \bmod m)$ のとき，次のことが成り立つ。


<ul>
	<li>$a+c \equiv b+d ( \bmod m)$</li>
	<li>$a-c \equiv b-d ( \bmod m)$</li>
	<li>$ac \equiv bd ( \bmod m)$</li>
	<li>自然数 $m$ に対し $a^n \equiv b^n ( \bmod m)$</li>
</ul>
