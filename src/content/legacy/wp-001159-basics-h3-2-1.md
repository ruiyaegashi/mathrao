## 放物線




【定義】




<strong>放物線</strong>：平面上で，定点 $\mathrm{F}$ からの距離と，$\mathrm{F}$ を通らない定直線 $l$ からの距離が等しい点の軌跡




<strong>放物線の方程式の標準形</strong>：$y^2=4px$ ( $p\neq 0$ )




<strong>焦点</strong>：放物線の定義における点 $\mathrm{F}$




<strong>準線</strong>：放物線の定義における定直線 $l$




【定理】




<strong>放物線の性質</strong>




放物線 $y^2=4px$ ( $p\neq 0$ )


<ul>
	<li>頂点：原点</li>
	<li>焦点：点 $(p,0)$</li>
	<li>準線：直線 $x=-p$</li>
	<li>軸：$x$ 軸</li>
	<li>曲線は軸に関して対称</li>
</ul>


放物線 $x^2=4py$ ( $p\neq 0$ )


<ul>
	<li>頂点：原点</li>
	<li>焦点：点 $(0,p)$</li>
	<li>準線：直線 $y=-p$</li>
	<li>軸：$y$ 軸</li>
	<li>曲線は軸に関して対称</li>
</ul>

## 楕円




【定義】




<strong>楕円</strong>：平面上で，2定点 $\mathrm{F}$，$\mathrm{F'}$ からの距離の和が一定である点の軌跡




<strong>楕円の方程式の標準形</strong>：$\displaystyle{\frac{x^2}{a^2}+\frac{y^2}{b^2}=1}$ ( $a&gt;b&gt;0$ )




<strong>焦点</strong>：楕円の定義における2点 $\mathrm{F}$，$\mathrm{F'}$




<strong>長軸</strong>：楕円によって切り取られた座標軸の長い方




<strong>短軸</strong>：楕円によって切り取られた座標軸の短い方




【定理】




<strong>楕円の性質</strong>




楕円 $\displaystyle{\frac{x^2}{a^2}+\frac{y^2}{b^2}=1}$ ( $a&gt;b&gt;0$ )


<ul>
	<li>楕円上の任意の点から2つの焦点までの距離の和：$2a$</li>
	<li>中心：原点</li>
	<li>長軸の長さ：$2a$</li>
	<li>短軸の長さ：$2b$</li>
	<li>焦点：$\mathrm{F}(\sqrt{a^2-b^2},0)$，$\mathrm{F'}(-\sqrt{a^2-b^2},0)$</li>
	<li>曲線は $x$ 軸，$y$ 軸，原点に関して対称</li>
	<li>円 $x^2+y^2=a^2$ を $x$ 軸をもとにして $y$ 軸の方向に $\frac{b}{a}$ 倍に縮小した曲線</li>
</ul>


楕円 $\displaystyle{\frac{x^2}{a^2}+\frac{y^2}{b^2}=1}$ ( $b&gt;a&gt;0$ )


<ul>
	<li>楕円上の任意の点から2つの焦点までの距離の和：$2b$</li>
	<li>中心：原点</li>
	<li>長軸の長さ：$2b$</li>
	<li>短軸の長さ：$2a$</li>
	<li>焦点：$\mathrm{F}(0,\sqrt{a^2-b^2})$，$\mathrm{F'}(0,-\sqrt{a^2-b^2})$</li>
	<li>曲線は $x$ 軸，$y$ 軸，原点に関して対称</li>
	<li>円 $x^2+y^2=b^2$ を $y$ 軸をもとにして $x$ 軸の方向に $\frac{a}{b}$ 倍に縮小した曲線</li>
</ul>

## 双曲線




【定義】




<strong>双曲線</strong>：平面上で，2定点 $\mathrm{F}$，$\mathrm{F'}$ からの距離の差が一定である点の軌跡




<strong>双曲線の方程式の標準形</strong>：$\displaystyle{\frac{x^2}{a^2}-\frac{y^2}{b^2}=1}$ ( $a&gt;0$，$b&gt;0$ )




<strong>焦点</strong>：双曲線の定義における2点 $\mathrm{F}$，$\mathrm{F'}$




【定理】




<strong>双曲線の性質</strong>




双曲線 $\displaystyle{\frac{x^2}{a^2}-\frac{y^2}{b^2}=1}$ ( $a&gt;0$，$b&gt;0$ )


<ul>
	<li>双曲線上の任意の点から2つの焦点までの距離の差：$2a$</li>
	<li>中心：原点</li>
	<li>頂点：$(a,0)$，$(-a,0)$</li>
	<li>焦点：$\mathrm{F}(\sqrt{a^2+b^2},0)$，$\mathrm{F'}(-\sqrt{a^2+b^2},0)$</li>
	<li>曲線は $x$ 軸，$y$ 軸，原点に関して対称</li>
	<li>漸近線：$y=\pm\displaystyle\frac{b}{a}x$</li>
</ul>


双曲線 $\displaystyle{\frac{x^2}{a^2}-\frac{y^2}{b^2}=-1}$ ( $a&gt;0$，$b&gt;0$ )


<ul>
	<li>楕円上の任意の点から2つの焦点までの距離の和：$2b$</li>
	<li>中心：原点</li>
	<li>頂点：$(0,b)$，$(0,-b)$</li>
	<li>焦点：$\mathrm{F}(0,\sqrt{a^2+b^2})$，$\mathrm{F'}(0,-\sqrt{a^2+b^2})$</li>
	<li>曲線は $x$ 軸，$y$ 軸，原点に関して対称</li>
	<li>漸近線：$y=\pm\displaystyle\frac{b}{a}x$</li>
</ul>


&nbsp;




## 2次曲線の平行移動




曲線 $F(x,y)=0$ を $x$ 軸方向に $p$，$y$ 軸方向に $q$ だけ平行移動して得られる曲線の方程式は


<p style="padding-left: 30px;">$F(x-p,y-q)=0$</p>


方程式が標準形で表される2次曲線を平行移動したときの曲線の方程式は


<p style="padding-left: 30px;">$ax^2+cy^2+dx+ey+f=0$</p>


2次曲線を平行移動だけでなく，回転・対称移動したときの曲線の方程式は


<p style="padding-left: 30px;">$ax^2+bxy+cy^2+dx+ey+f=0$</p>
<p style="padding-left: 30px;">※平行移動だけなら $xy$ の項は現れない。</p>
