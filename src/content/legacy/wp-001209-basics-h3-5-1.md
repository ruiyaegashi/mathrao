## 微分係数と導関数




【定義】




<strong>微分係数</strong>




関数 $f(x)$ の $x=a$ における<strong>微分係数</strong> $\boldsymbol{f'(a)}$ は


<p style="padding-left: 30px;">$f'(a)= \displaystyle \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}=\displaystyle\lim_{x\to a}\frac{f(x)-f(a)}{x-a}$</p>


$\boldsymbol{x=a}$ <strong>で連続</strong>




関数 $f(x)$ が $x=a$ で微分可能ならば，$f(x)$ は $\boldsymbol{x=a}$ <strong>で連続</strong>である。(逆は不成立)




<strong>導関数</strong>




関数 $f(x)$ の導関数 $f'(x)$ は


<p style="padding-left: 30px;">$f'(x)= \displaystyle \lim_{h \to 0} \frac{f(x+h)-f(x)}{h}=\displaystyle\lim_{\Delta x\to 0}\frac{\Delta y}{\Delta x}$</p>


&nbsp;




## 導関数の公式




【定理】




関数 $f(x)$，$g(x)$ は微分可能であり，$k$，$l$ を定数とする。




<strong>導関数の性質</strong>


<ul>
	<li>定数倍：$\{kf(x)\}'=kf'(x)$</li>
	<li>和：$\{f(x)+g(x)\}'=f'(x)+g'(x)$</li>
	<li>差：$\{f(x)-g(x)\}'=f'(x)-g'(x)$</li>
	<li>$\{kf(x)+lg(x)\}'=kf'(x)+lg'(x)$</li>
</ul>


<strong>積の導関数</strong>


<ul>
	<li>$\{f(x)g(x)\}=f'(x)g(x)+f(x)g'(x)$</li>
</ul>


<strong>商の導関数</strong>


<ul>
	<li>$\displaystyle{\left\{\frac{f(x)}{g(x)}\right\}'=\frac{f'(x)g(x)-f(x)g'(x)}{\{g(x)\}^2}}$</li>
	<li>$\displaystyle{\left\{\frac{1}{g(x)}\right\}'=-\frac{g'(x)}{\{g(x)\}^2}}$</li>
</ul>


<strong>合成関数の導関数</strong>




$y=f(u)$ が $u$ の関数として微分可能，$u=g(x)$ が $x$ の関数として微分可能であるとき


<ul>
	<li>$\displaystyle{\frac{dy}{dx}=\frac{dy}{du}\cdot\frac{du}{dx}}$ すなわち $\{f(g(x))\}'=f'(g(x))g'(x)$</li>
</ul>


特に，$a$，$b$ を定数，$n$ を整数とすると


<ul>
	<li>$\{f(ax+b)\}'=af'(ax+b)$</li>
	<li>$[\{f(x)\}^n]'=n\{f(x)\}^{n-1}f'(x)$</li>
</ul>


<strong>逆関数の導関数</strong>


<ul>
	<li>$\displaystyle{\frac{dy}{dx}=\frac{1}{\frac{dx}{dy}}}$</li>
</ul>


$\boldsymbol{x^p}$ <strong>の導関数</strong>




$p$ が有理数のとき


<ul>
	<li>$(x^p)'=px^{p-1}$</li>
</ul>
