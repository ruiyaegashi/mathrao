## 塾・指導の種類




中学生になると自転車等が使えるので，<strong>通塾できる範囲も広がります</strong>。




しかし，平日に何度か通うとなると，やはり<strong>家か学校の近くの方が断然良い</strong>です。




通塾にかかる<strong>時間がもったいない</strong>ですしね。




通塾が難しいなら，自宅で受講できる<strong>映像授業や通信教育等</strong>もあるので，ぜひ選択肢に入れてください。




<strong>指導方法も多様化している</strong>ので，以下，指導の種類とメリット，デメリットをまとめました。




塾によって<strong>指導方法の呼び方が違います</strong>し，組み合わせている塾がほとんどなので，パンフレット等で確認し，検討してみてください。




特に最近よく見る<strong>「個別指導」</strong>というのが<strong>「指導の最初から最後までマンツーマン」とは限らない</strong>ので注意が必要です。




費用に関してはピンきりとしか言えないのですが，<strong>高いから良い，安いから悪いとは一概にはいえません</strong>。




※フォロー：学習に関する助言　サポート：学習以外に関する助言




### 集団指導




講師：1人




生徒：5人～30人




形式：授業形式




メリット


<ul>
	<li>塾に通うので，ある程度の拘束力がある</li>
	<li>同年代と授業を受けるので，切磋琢磨できる</li>
	<li>目標がはっきりとしている</li>
	<li>生徒数が絶対的に多いため，塾単位，講師単位の実績がはっきり分かる</li>
	<li>講師が養成されているため，良い講師に教わることができる可能性が高い</li>
	<li>学生バイト講師が少ない</li>
</ul>


デメリット


<ul>
	<li>フォロー・サポートが少ない</li>
	<li>授業についていけないと一気にやる気が無くなる可能性がある</li>
	<li>塾に行っただけで勉強した気になりやすい</li>
	<li>自律が促されない</li>
</ul>


### 個別指導




講師：1人




生徒：1人




形式：自由




メリット


<ul>
	<li>塾に通うので，ある程度の拘束力がある</li>
	<li>目標，授業内容が自由に決められる</li>
	<li>講師との相性が良ければ目標が達成しやすい</li>
	<li>学生バイト講師が少ない</li>
	<li>講師がつきっきりなので，フォロー・サポートが細やか</li>
</ul>


デメリット


<ul>
	<li>同年代と接することがないので，切磋琢磨できない</li>
	<li>生徒数が絶対的に少ないため，塾単位，講師単位の実績が分かりづらい</li>
</ul>


### 自習指導




講師：1人




生徒：2～10人




形式：講師が課題を指定し，自習する形式




メリット


<ul>
	<li>塾に通うので，ある程度の拘束力がある</li>
	<li>塾のテキストを使った学力向上のみを目的としている</li>
	<li>個別指導には劣るが，講師がある程度フォロー・サポートしてくれる</li>
	<li>自律が促される</li>
</ul>


デメリット


<ul>
	<li>同年代と接することが少ないので，切磋琢磨しづらい</li>
	<li>自習なので，塾単位，講師単位の実績が分からない</li>
	<li>学生バイト講師が多い</li>
	<li>先生1人に対しての生徒数によってフォローが変動する</li>
</ul>


### プリント指導




講師：1人




生徒：多数




形式：パソコンでプリントを印刷し，講師が添削する形式




メリット


<ul>
	<li>塾に通うので，ある程度の拘束力がある</li>
	<li>プリントシステムに沿った学力向上のみを目的としている</li>
	<li>自律が促される</li>
</ul>


デメリット


<ul>
	<li>同年代と接するかどうかは運次第</li>
	<li>自習なので，塾単位，講師単位の実績が分からない</li>
	<li>学生バイト講師が多い</li>
	<li>フォロー・サポートがほぼない</li>
</ul>


### 管理指導




講師：1人 or 複数




生徒：多数




形式：講師が課題を指定し，自習する形式




メリット


<ul>
	<li>塾に通うので，ある程度の拘束力がある</li>
	<li>目標(中学受験，検定，学力向上等)が自由に決められる</li>
	<li>塾単位の実績が分かりやすい</li>
	<li>学生バイト講師が少ない</li>
	<li>計画と実施に重きを置いているのでサポートが細やか</li>
	<li>自律が促される</li>
</ul>


デメリット


<ul>
	<li>同年代と接することが少ないので，切磋琢磨しづらい</li>
</ul>


※自習指導との境目が曖昧ですが，目標，教材の自由度が高いところは管理指導と考えて問題ありません。




### 映像授業(通塾)

</ul>

</ul>

<ul>
	<li>目標に合わせて自由に授業を受けることができる</li>
	<li>サービス単位の実績が分かりやすい</li>
	<li>有名講師の授業を受けることができる</li>
	<li>学生バイト講師はいない</li>
	<li>自律が促される</li>
</ul>

### 家庭教師




講師：1人




生徒：1人




形式：自宅に来て指導をしてもらう形式




メリット


<ul>
	<li>塾には通わないが，ある程度の拘束力がある</li>
	<li>目標，授業内容が自由に決められる</li>
	<li>講師との相性が良ければ目標が達成しやすい</li>
	<li>講師がつきっきりなので，フォローが細やか</li>
</ul>


デメリット


<ul>

	<li>学生バイト講師がほとんど(社会人プロ講師もいるが割高)</li>
	<li>サポートがほぼない</li>
	<li>自律が促されない</li>
</ul>

形式：送られてくる教材を使って学習し，毎月テストを添削してもらう形式，または，タブレット学習形式




メリット


<ul>
	<li>目標に合わせて自由に教材を選ぶことができる</li>
	<li>サービス単位の実績が分かりやすい</li>

## 選び方




このように指導方法は多様でそれぞれ<strong>一長一短があります</strong>。




中学生であれば<strong>自分で良し悪しを判断できる</strong>ので，体験授業を受けて決めましょう。




1，2年生のうちは在宅で，と，<strong>映像授業や通信教育を選択する方も多い</strong>と思います。




ただ，<strong>教材も進化はしている</strong>のですが，慣れていないと<strong>自律するのは難しい</strong>でしょう。




<strong>質問ができない</strong>というのも，勉強がはかどらない原因ですし。




在宅の場合，<strong>部活で疲れて勉強したくても寝てしまう</strong>，ということにもなりかねないので，<strong>強制性を求めて通塾する</strong>のもありです。




また，<strong>勘違いしやすいポイント</strong>がいくつかあります。


<ul>
	<li>今まで一切家で勉強をしていなかったなら，塾へ行って授業を受けて宿題までこなせば<strong>必ず学力は伸びる</strong></li>
	<li>塾に行っている状態とそうでない状態を<strong>比べることは物理的にできない<br />
</strong>(塾へ行って成績が落ちても，塾に行かなかったらもっと悪かったかもしれませんし，塾へ行って成績が上がっても，塾のおかげかどうかは分かりません。</li>
	<li>塾の影響が<strong>結果に反映されるまで2，3ヶ月程度はかかる</strong></li>
</ul>


加えて，<strong>保護者が結果に固執する</strong>と，それが<strong>子どもに伝わり</strong>，<strong>勉強嫌いの元凶になります</strong>ので，ご注意ください。




## 評価ポイント




中学生の学力向上，高校受験対策の塾は多く，それぞれ<strong>差別化が進んでいます</strong>。




中学受験と違って<strong>学力も差がつく</strong>ので，塾内で<strong>レベル別の授業</strong>を行っていたり，<strong>入塾試験</strong>によって入塾可否が決まったりすることも。




そこで，塾選びの評価ポイントをまとめました。




### 立地




言わずもがな，通塾にかかる時間が<strong>短ければ短いほど良い</strong>です。




往復で2時間以上かかるのであれば，その分を勉強時間に回すべきです。




どうしても近所にない場合は，<strong>映像授業や通信教育等</strong>を検討しましょう。




### 実績と対応




学力向上の実績，というのは開示されていないでしょうから，自ずと<strong>高校受験の実績</strong>になります。




ただ，高校受験の実績というのは<strong>見極めが難しく，難関校に多く合格しているから良い塾とはいえません</strong>。




大手は<strong>生徒数が多く，優秀な生徒も集まる</strong>ので自ずと<strong>合格者数も増えます</strong>。




個人塾では<strong>大手の授業に合わなかった，ついていけなかった生徒を成長させている可能性があります</strong>。




ですので，塾のスタッフと面談をして，具体的に<strong>どのレベルの生徒がどう成長したか</strong>を聞き出しましょう。




<strong>丁寧に対応してくれない</strong>塾は最初から対象外にしたほうが賢明です。




中学生までは<strong>子ども，親，塾の連携</strong>は重要ですから。




### 国語の指導力




意外かもしれませんが，<strong>国語の指導ができる塾</strong>は良い塾が多いです。




国語以外の教科は，一般に売られている参考書も豊富で比較的成績が伸ばしやすいのですが，国語はそうはいかないのです。




小中高通して<strong>何を勉強したらいいか分からない教科No.1の国語</strong>。




その国語で確実に点を取るためには，漢字，文法，読解等の力をつける必要があるのですが，その<strong>ノウハウを持っている塾はカリキュラムがしっかりしている</strong>といえます。




集団指導塾では国語の授業を開講していることが多いのですが，個別となると<strong>おざなりにされがち</strong>ですので。




国語は<strong>他の教科にも大きな影響を及ぼす</strong>ので，手を抜いてはいけません。




## 中学生がつけたい力




ちなみに，どこの塾に行ったとしても<strong>達成したい目標</strong>が2つあります。




1つは，「<strong>計画通りに勉強すること」</strong>。




計画は学校や塾の先生と立ててもいいので，それを<strong>着実にこなす</strong>ということです。




中学生になると勉強量が増えるので，闇雲に勉強していたのでは<strong>定期試験や受験で結果を出すことはできません</strong>。




こうなるためにはこれだけの勉強が必要で，本番までにこれくらいのペースで進めなければならない，というところまで理解することが大事。




常に遠くの目標を見ることで，<strong>大事なことを先延ばしにする癖がつくのを防げます</strong>。




もう1つは，「<strong>自分で解決すること</strong>」。




小学生まではなかなか難しいのですが，中学生になったら文章を読む力もつくので，分からないことがあったら<strong>自分で調べて解決しましょう</strong>。




調べる，というのは<strong>学習の基本</strong>です。




どの本にどんなことが書かれていて，どれを使えば解決できるか，ということを自然に<strong>判断できるようになること</strong>が重要。




人に聞かなければ解決できない，から卒業することで<strong>自学力がグンと伸びます</strong>。
